# nkon-stock-checker
📦 NKON Stock Monitor
Цей простий і надійний помічник автоматично моніторить наявність потрібних товарів (інверторів та акумуляторів Deye) на сайті nkon.nl і надсилає сповіщення в Telegram тільки тоді, коли статус товару реально змінюється.

📂 З чого складається проєкт:
products.txt — головний список. Тут зберігаються посилання на товари, за якими ви хочете стежити (кожне посилання з нового рядка).

check_stock.py — головний скрипт («мозок» системи). Він заходить на сайт NKON, аналізує сторінку і визначає, чи є товар в наявності, на передзамовленні, чи розпроданий.

status_cache.json — файл пам'яті (кешу). У ньому бот зберігає останні відомі статуси товарів, щоб порівнювати їх під час наступного занурення й уникнути зайвих повідомлень.

.github/workflows/check.yml — інструкція для GitHub, яка каже йому, як і коли запускати скрипт на виконання.

🛠 Як додати новий товар для моніторингу:
Якщо ви хочете додати ще один товар на перевірку, це робиться дуже просто:

Зайдіть у ваш репозиторій на GitHub.

Відкрийте файл products.txt.

Натисніть іконку олівця (Edit) у правому верхньому кутку файлу.

Додайте повне посилання на новий товар з нового рядка.

Натисніть зелену кнопку Commit changes.

Готово! Під час наступного автоматичного запуску скрипт сам підхопить нове посилання, збереже його початковий стан і почне за ним стежити.

⏱ Як працює автоматика:
Розклад: Зовнішній сервіс cron-job.org регулярно надсилає сигнал на GitHub.

Виконання: GitHub Actions запускає Python-скрипт усередині хмари.

Сповіщення: Якщо статус якогось товару змінився, ви отримуєте акуратне повідомлення в Telegram. Якщо все по-старому — система працює тихо і нікого не турбує.
